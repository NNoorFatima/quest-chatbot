# FAST University Chatbot

This is a basic chatbot that provides information about FAST National University.

## Features
- Responds to basic queries about FAST University
- Fetches real-time information from the FAST website for admissions and courses

## Requirements
- Python 3.8+
- Dependencies: requests, beautifulsoup4

## Installation
1. Create a virtual environment: `python -m venv venv`
2. Activate it: `venv\Scripts\activate` (Windows)
3. Install dependencies: `pip install -r requirements.txt`

## Usage
Run the chatbot: `python src/chatbot.py`

Ask questions like:
- Hello
- What are the admission requirements?
- What courses do you offer?
- Where are you located?
- How can I contact you?
- Bye

## Note
This chatbot fetches data from https://www.fast.nu.edu.pk/. Ensure you have internet connection.
